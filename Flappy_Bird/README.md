# Flappy Bird Clone

A simple Flappy Bird-inspired arcade game built with Python and Pygame. This project is a fun, lightweight clone that lets you flap through randomly generated pipes, track your score, and restart after a game over.

## Demo

![Gameplay Screenshot](assets/bg_5.png)

## Features

- Smooth bird movement and gravity-based physics
- Randomly generated pipe obstacles
- Score tracking as you pass pipes
- Restart button after game over
- Scrolling background and ground animation
- Lightweight and beginner-friendly Pygame implementation

## Tech Stack

- Python 3
- Pygame

## Requirements

Before running the game, make sure you have Python installed. Then install the required dependency:

```bash
pip install pygame
```

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/Flappy_Bird.git
```

2. Navigate to the project folder:

```bash
cd Flappy_Bird
```

3. Run the game:

```bash
python main.py
```

## How to Play

- Click the left mouse button to make the bird flap upward
- Avoid the pipes
- Survive as long as possible
- Press the restart button after a collision to play again

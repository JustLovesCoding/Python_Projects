# Python Projects

This folder contains a small collection of beginner-friendly Python projects designed to practice core programming concepts through real-world mini applications.

## Overview

The `Python_Projects` folder is a learning space where different small programs are grouped together to explore:

- object-oriented programming
- class design and relationships
- lists and dictionaries
- user interaction in console apps
- building simple systems from scratch
- clean project organization

These projects are intentionally lightweight and beginner-focused, making them ideal for learning how to structure code and build useful mini applications.

## Included Projects

### 1. Budget App
Location: [budget_app](budget_app)

This project is a simple budgeting tracker that helps manage finances by creating categories, recording deposits and withdrawals, checking balances, and moving money between categories.

It focuses on:
- transaction tracking
- balance calculations
- category-based spending
- formatted output
- Python class logic

Main file: [budget_app/Budget_app.py](budget_app/Budget_app.py)

### 2. Mail Simulator
Location: [mail_simulator](mail_simulator)

This project simulates a basic email system where users can send messages, view their inbox, read emails, and delete them.

It focuses on:
- user and inbox management
- message storage
- read/unread status
- basic object modeling
- interaction between classes

Main file: [mail_simulator/main.py](mail_simulator/main.py)

## Purpose of This Folder

This folder acts as a portfolio of small Python projects that show progression in learning. Each project is independent, but together they demonstrate how Python can be used to model real-life systems such as a personal budget and a simple messaging app.

## How to Use

Open any project folder and run the main file from that location.

Example:

```bash
cd Python_Projects/budget_app
python Budget_app.py
```

```bash
cd Python_Projects/mail_simulator
python main.py
```

## Notes

These projects are simple console-based applications and are meant for learning, experimentation, and practice rather than production-level software.
